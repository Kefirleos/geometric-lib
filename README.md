# Geometric Lib

Библиотека математических и геометрических функций для расчёта характеристик двумерных фигур и трёхмерных тел.

---

## Сводная таблица математических формул

| Фигура / Тело | Модуль | Площадь ($S$) | Периметр ($P$) / Объём ($V$) |
| :--- | :--- | :--- | :--- |
| **Круг** | `circle.py` | $S = \pi r^2$ | $P = 2\pi r$ |
| **Квадрат** | `square.py` | $S = a^2$ | $P = 4a$ |
| **Прямоугольник** | `rectangle.py` | $S = a \cdot b$ | $P = 2(a + b)$ |
| **Треугольник** | `triangle.py` | $S = \frac{a \cdot h}{2}$ | $P = a + b + c$ |
| **Сфера (3D)** | `sphere.py` | $S = 4\pi r^2$ | $V = \frac{4}{3}\pi r^3$ |

---

## Примеры использования

```python
from circle import area as circle_area
from triangle import area as triangle_area
from sphere import volume as sphere_volume

# Вычисление площади круга радиуса 5
print(f"Площадь круга: {circle_area(5):.2f}")

# Вычисление целочисленной площади треугольника (основание 4, высота 5)
print(f"Площадь треугольника: {triangle_area(4, 5)}")

# Вычисление объёма сферы радиуса 4
print(f"Объём сферы: {sphere_volume(4):.2f}")
```
